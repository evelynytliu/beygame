# Neon Spinner: Ultimate Arena 🌀

一款行動裝置優先的 3D 戰鬥陀螺遊戲。組裝零件、繪製專屬塗裝、用真實的拉繩手感發射，挑戰十位越來越強的對手。

## 玩法

1. **陀螺工坊** — 組合三種零件打造你的陀螺：
   - **刃盤**（9 種）：決定攻擊型態、形狀與範圍 — 三刃、圓盾、六角、星芒、鋸刃、光環，以及傳說級的龍牙、極光、深淵
   - **配重環**（5 種）：決定重量與慣性 — 輕量、標準、重裝，以及傳說級的合金環、泰坦環
   - **軸尖**（6 種）：決定移動方式 — 尖針（定點持久）、圓球（平衡）、平底（場內暴走）、橡膠（吸收衝擊），以及傳說級的鑽頭軸（爆裂傷害 +30%）、磁吸軸（穩定抓地）
   - **★ 傳說級零件**：工坊中標示 ★ 的高價零件，全面高於一般零件，是挑戰「月蝕」之後強敵的關鍵
   - **塗裝**：手繪陀螺面圖案，會即時貼到 3D 模型上
2. **技術性發射** — 按住發射器往下拉；拉繩長度決定力道，拉進「綠色甜蜜區」並在末端快速甩開手指可獲得 **PERFECT** 發射（+15% 轉速）；拉過頭會暴衝失控。左右拖曳瞄準進場角度。熟能生巧！
3. **戰鬥操作** — 拖曳畫面傾斜戰鬥碗操控走位；⚡ 爆發鍵（3 次）衝刺撞擊；注意橘色爆裂條，被打滿會直接爆裂敗北。
4. **三種勝利方式** — Spin Finish（對手停轉）、Over Finish（擊出場外）、Burst Finish（打爆對手）。
5. **進度系統** — 贏得金幣解鎖更強零件，一路打到世界冠軍「王者・天龍」。

## 技術

- 純前端：Three.js（已打包於 `js/vendor/`，無 CDN 依賴）＋ WebAudio 程序化音效／音樂 ＋ `navigator.vibrate` 觸覺回饋
- PWA：可安裝到主畫面、Service Worker 離線快取
- 進度以 `localStorage` 保存

## 本地執行

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

直接開 `index.html` 也能玩（Service Worker 需經由 http(s) 才會啟用）。
